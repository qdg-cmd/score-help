# 🧭 고교 성적 나침반 5.0 (High School Compass 5.0)

> **2028 대입 개편 5등급제 고교 성적 종합 분석 및 진학 상담 웹 애플리케이션 (PWA)**

---

## 🌟 주요 기능

1. **2028 대입 개편 5등급제 완벽 지원**
   - 2028 개편 5등급제 누적 백분위(1등급 10%, 2등급 34%, 3등급 66%, 4등급 90%, 5등급 100%) 기준의 고교 성적 산출 및 분석
2. **M3 모던 카드 대시보드 (Clean Card Dashboard)**
   - **학생 핵심 지표(KPI) 요약 바**: 학생별 종합 등급 평균, 이수 학점, 교과별 강약점 요약
   - **1. 5등급 교과 종합 성적표**: 이수단위 가중 평균, 성취도, 등급 및 구간 내 상대적 백분위 위치 상세 표
   - **2. 5등급 위치 및 추월 가능 과목 (Near-Miss)**: 상위 등급 커트라인까지 1~3명 남은 역전 유망 과목 목표 시뮬레이션
   - **3. AI 맞춤 상담 프롬프트 생성기**: 학생 상담용 / 학부모 상담용 원클릭 프롬프트 생성 및 복사
   - **4. 과목별 등급 추이 & 방사형(Radar) 시각화**: 학기별 변화 그래프 및 과목군별 이수 비중 한눈에 파악
3. **완벽한 개인정보 보안 (100% 오프라인 & 클라이언트 사이드 처리)**
   - 나이스(NEIS) 엑셀 성적 파일은 외부 서버로 일절 전송되지 않으며, 교사의 브라우저 메모리 안에서만 안전하게 처리됩니다.
4. **다기종 반응형 & PWA 지원**
   - PC 모니터는 물론 5.5인치 소형 스마트폰, 갤럭시 폴드4, 태블릿(iPad, Galaxy Tab) 환경에 완벽 대응합니다.
   - PWA(프로그레시브 웹 앱)로 스마트폰 홈 화면에 바로가기 앱으로 설치할 수 있습니다.

본 폴더(`github-upload`)의 파일들을 GitHub 저장소에 업로드한 뒤, **Settings > Pages**에서 `Deploy from a branch` (Branch: `main` / `root`)로 지정하면 무료 웹 앱(`https://<아이디>.github.io/<저장소명>/`)으로 즉시 가동됩니다.
